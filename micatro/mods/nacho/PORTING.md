# Nacho's Pokermon Dip — porting notes

Nacho's Pokermon Dip (Eternalnacho & contributors, GPL-3.0) is a Pokermon add-on, rebuilt natively for Micatro
(`registerMod` id `nacho`, prefix `nacho`, requires `pokermon`). Owner rule: **base Pokermon wins any conflict**
(micatro/mods/pokermon/PORTING.md "Add-on dedupe (Pokermon precedence)").

- **Source**: github.com/Eternalnacho/NachosPokermonDip, `main` at **904ae3979b8e3d18348c2b9c819c1692daf9d61e**

### Retired keys: legacy definitions vs aliases (batch 18)

1.7.9 moves its Ralts, Swablu, Bagon (and the never-ported Bronzor / Smoliv) lines to `src/pokemon/deprecated/` with
`can_load = false`: base Pokermon 3.7–3.9 owns those Pokémon. Our 1.6.4 port already had the nine duplicates out of play
(checkpoint 1: `mark_precedence`). The choice was `renamed` aliases (`j_nacho_ralts` -> `j_poke_ralts`) or keeping the legacy
definitions. **Kept as legacy definitions** (`pokemon/legacy/`, 1.6.4 behaviour on 1.6.4 data, `nacho_legacy: '1.6.4'`):
- An alias only acts once the old key is unregistered: an owned `j_nacho_ralts` in a save or replay would turn into Pokermon's
  Ralts — a different card (Nacho's: +1 Mult per hand level, 4 rounds; Pokermon's: its own) — and the re-simulation would
  diverge silently. Registered, it keeps playing as it did; only its evolutions go to Pokermon's (precedence).
- The win-sticker merge (`js/mods/superseded.js`, generated by `tools/micatro/gen_superseded.mjs` from `replaced_by` over the
  registered keys) keeps its 12 rows unchanged: a legacy win still counts for Pokermon's twin, and the legacy card keeps its own
  name, text, art and sticker. An alias would have needed the merge rebuilt on `aliasesOf`, for no gain.
- They are out of every pool (shops, packs, tags, random Pokémon: `in_pool` false + a `POKE_POOL_RULES` entry) and have no line
  option (an option off would make an OWNED card inactive). The 1.6.4 options (`Ralts`, `Swablu`, `Bagon`, `customStakes`,
  `orderJokers`, `pokemon_only`) are gone; a stored value in an old recipe is ignored.
- Mega Salamence: 1.7.9 DROPPED it (no file). Also legacy (registered for old saves); nothing reaches it any more — Pokermon's and
  the legacy Salamence have no Mega.

What 1.7.9 RE-KEYED is aliased (`registerMod({aliases: {renamed}})`, js/mods/aliases.js; the old keys are no longer registered):

| Old key (1.6.4) | New key (1.7.9) | |
|---|---|---|
| `j_nacho_mega_gardevoir` | `j_poke_mega_gardevoir` | registered by Nacho (`nacho_inject_prefix = "poke"`), attached to Pokermon's Gardevoir |
| `j_nacho_mega_altaria` | `j_poke_mega_altaria` | attached to Pokermon's Altaria |
| `j_nacho_mega_gallade` | `j_poke_mega_gallade` | attached to Pokermon's Gallade |
| `stake_nacho_elite_stake` | `stake_poke_elite` | Pokermon's Elite stake (batch 17); Nacho registers no stake now |

- The Megas: 1.7.9's `init()` does `SMODS.Joker:take_ownership('poke_gardevoir', {megas = {'mega_gardevoir'}})` +
  `pokermon.add_to_family`. Micatro mods are per run, so Pokermon's center is never rewritten: `attach_mega` (Pokermon
  precedence.js) lists the Mega for `addon_megas` while it is active (Nacho on, its `Mega_*` option on). A legacy Gardevoir /
  Altaria / Gallade (an old save) reaches the same re-keyed Mega. Each Mega is a 1.7.9 rework (below).
- A stored old key resolves when it is read: a recipe's stake (`newRun`), a custom deck's jokers, a win sticker (`aliasesOf`).
- Nothing is `removed` (retired): every 1.6.4 key either still loads or resolves.

Not registered at all (never in our port): 1.7.9's deprecated Bronzor / Smoliv lines, the Impidimp line (`can_load = false`
upstream), the G-Max Flapple / Appletun (`can_load` only with Agarmons).

### Deviations (contentRev 2)

Intended-design fixes and Micatro shapes, each marked in the code:
- **Palafin-Hero**: the Lua starts a card's `perma_x_mult` at 1 (`or 1`), so the first Bonus card jumped to +X1.05; ours starts at
  0 (Steamodded's default, the card text's "+X0.05").
- **Mega Gallade**: the Lua replaces a non-table `extra` with `{e_limit_up = 1}` (a base joker's number lost); ours keeps it and
  counts the bonus in `ability.nacho_e_limit_up` (Pokermon `ENERGY_LIMIT_BONUS`).
- **Dhelmise** (`PkmnDip.eff.joker_as_card`): the temporary held Steel card is a real card in G.hand for the hand, hidden, not in
  the deck count, removed after; its rank is a fixed -1000 (the Lua: a random negative number from the unseeded `math.random`).
- **Victini**: its code gains X0.05 on every rolled probability (`from_roll`); the card text says "when one succeeds". The code
  is ported.
- **press_play timing**: Steamodded fires press_play after Blind:press_play (the played cards' moves already queued); Micatro just
  before (Pokermon's Zangoose depends on it). Solosis' copies and Rampardos' count are one event later (`dip.js defer_after_play`).
- `G.GAME.blind.in_blind` is Micatro's `G.GAME.facing_blind`; `PkmnDip.slots_reserved` (Palafin) takes the slot off the joker
  area's `card_limit` while reserved.
- Energy with an amount (Galarian Meowth / Perrserker's `pokermon.energy.modify(j, t, ±n)`): `dip.js modify_energy` follows 3.9.1's
  formula for a table `extra` (our Pokermon port's `energize` has no amount).
- Not ported (cosmetic): the "Dip+BFP" mod badge, the "better fossil UI" option, the Tera Orb's Stellar text override, JokerDisplay.

### Engine / Pokermon seams added (all inert without Nacho)
- `js/engine/core.js`: Card:set_debuff -> hook `debuff_set` (Turtonator); get_chip_h_x_mult -> hook `chip_h_x_mult` (Dhelmise).
- `js/engine/run.js`: hook `held_card_evaluated` after each held card's scoring / end-of-round pass (Dedenne's dedenne_trig).
- `js/engine/view.js` + `js/ui/cardsprite.js`: a center's `soul_atlas`; soul-only animations.
- Pokermon: `attach_mega` (precedence.js), `EVO_OVERRIDES` (evolution.js), the add-on prefix in `generate_pickup_item_key`
  (items.js), `soul_only` ANIMATED entries (anim.js / ui.js). Pokermon alone plays exactly as before (its pin is unchanged).
- Nacho opts into Steamodded's seams (`smods_seams: true`): modify_scoring_hand, ending_booster, modify_booster_card, the
  'unscored' destroy_card, the mod-level calculate.
